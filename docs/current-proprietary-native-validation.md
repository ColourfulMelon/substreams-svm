## Runtime acceptance

Every new spot source requires exactly two immediate committed native Token transfers, typed payload and accounts, exact declared input debit, positive output meeting the declared minimum, distinct bound mints, and exact principal transfer authorities. Token2022 output remains subject to the shared independently verified net receipt and minimum-output checks. A routed candidate must pass the same native settlement gate; unsupported native layouts cannot fall through generic amount matching. Success normalizes to the native protocol/program/pool/user identity and deduplicates only the same committed principal evidence.

Persistent pool-vault pre/post snapshots and the complete committed Token movement ledger also bind both receipts. This independently rejects a changed payout CPI even when the user WSOL account is closed; unknown vault balance-changing Token methods are rejected. The current Deriverse native transfer list additionally repeats its exact sole authority as a fourth SPL signer account. Only that identical single-authority suffix is accepted, and other authority suffixes are rejected.
