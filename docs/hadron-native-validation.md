# Hadron native receipt validation

The finalized `.24` baseline at slots **456081600–456085680** contains306 uncovered Hadron native calls: **305 real swaps and one close_pool**, which is excluded from pricing. All305 swaps independently match exact native financial tuples across **28 owned pools**, with **610 complete user ledgers** and full finalized RPC native/child commitment. Core tests pass all305 positives and **303 invalid mutations across13 settlement shapes**.

The primary ABI is published `@hadron-fi/sdk-v2@0.1.9`, tarball SHA256 **25a5ae42a0fbf655a8d586f95aafb3e9a64c3a91183141ec0577ae41750189b1**. Opcode3 is exactly26 bytes: direction bool, amountIn, minimum output, expiry. The bounded16–20 accounts include SDK-derived config/oracle/curve/update PDAs, token programs, input/output user accounts and reserves, exact fee-config PDA, fee-recipient input-mint ATA and Clock sysvar. Owned724-byte config pins seed, mint pair, token programs and curve identities; owned initialized canonical ATAs bind vault authorities/mints. Five currently closed pools retain config and initialized vault state while auxiliary curve/oracle accounts are absent; this is explicitly recorded under the SDK's Closed state4 and cannot prove historical reserves.

**301 swaps pay a separate input fee** directly from the source user account before the pool principal; four have no rounded fee CPI. Price input is the exact sum of both user debits, equal to amountIn. The pool principal retains source_transfer_index. The final recipient's proven net output after applicable Token-2022 fee is price output and must satisfy minimum proceeds. Fee rates from mutable current config never reconstruct historical paid fees: exact committed original CPIs establish the fee and principal. Curve/oracle/quote state is not a price.

The independent oracle checks complete original RPC/protobuf instructions, balances, token owners/decimals and runtime. It parses owned raw mint fee TLVs and independently checks parsed schedules, preserving source JSON digits for u64 maximumFee values. It also reconstructs full WSOL lifecycles including exact system deposits, SyncNative and close/recreate sequences; a token account recreated later in the transaction cannot conceal proceeds from the earlier lifecycle.

Original protobufs/RPC/inspection, SDK primary source, owned raw/parsed accounts, mint schedules, independent oracle and exact cases are retained in [`hadron-native`](../dex-swaps/fixtures/swap-coverage/hadron-native). These results are scoped to the immutable original corpus and do not establish universal historical/future swap coverage.
