# Archived wide CryptoQuest original

One finalized native market fill independently checked from the original retained PB and finalized RPC. The pure-log swap identity is retained; the three committed CPIs, burn plus gross QUEST input, exact CQT receipt, source-scoped MarketFill, both Town/bank roles and all four token bank ledgers prove the financial amount. Every resolved native lamport balance is also reconciled. Primary owned executable/layout traces are retained in ../cryptoquest-live26/README.md and its ProgramData/executable files. This is a finite one-fill archived scope, not a general classification of all game instructions.

Run with optional dependency package paths:

```sh
node oracle.cjs /absolute/path/to/backend/package.json /absolute/path/to/protobufjs/package.json
```

Default resolution also works with Node dependencies available in the normal module path. The fixture directory defaults to the script directory in package-path mode. Raw PBs are retained original source wire bytes, not reconstructed from RPC. Source/sourceTransfer/log positions are explicit in the independent financial proof. Checksums in sha256.json cover all retained evidence.
